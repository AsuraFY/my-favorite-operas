# Project guidelines

## Libretto outlines and act pages
- Each outline entry shows the original title, English translation, and the character icon when characters are present. Do not print character names beside the icon.
- Derive whether characters are present from the source libretto's character list, scene participants, and speaker labels. Never derive characters from Spotify performer metadata.
- Show the character icon in the libretto outline, the act outline, and beside the section heading in the side-by-side translation. Keep the actual speaker labels in the libretto text.
- Spotify may guide track order and scene grouping. It does not change the agreed outline format or provide the character source.
- Keep the Spotify album link at the bottom as the source, using a neutral label without performer credits.
- After pushing a page update, include the published page URL in the feedback.
