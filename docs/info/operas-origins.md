# Opera libretto origins

> **Canonical source register for My Favorite Operas** · Updated 2026-11-02 · Maintained on the `Update` branch.

This file records where the **original-language libretto** and **English-language text** used by each of the 35 opera readers came from. It consolidates provenance previously embedded in opera `bundle.js` files. These descriptions reflect the repository's recorded sources; **they are not external verification of edition, translation accuracy, permissions, or legal status**. A link to a comparison source must not be mistaken for the source actually reproduced. If no separate published English translation was used, say so explicitly. If exact provenance is unknown, it is marked **not recorded** rather than inferred.

For implementation status, editorial defects, verification runs and release readiness consult [the active audit](../reviews/global-audit.md); for opera presentation rules see the canonical Google Drive `Opera_Guidelines.md`. Do not duplicate progress reports in this register.

## Maintenance

When adding or correcting an opera, update the original-source and English-source fields **here** before changing bibliographic claims elsewhere. Preserve exact edition differences, primary versus comparison references, and unknown provenance. Operational source integrity hashes, internal imports and test fixtures may remain in code, but links and bibliographic descriptions should be centralized in this Markdown register. Editorial and licensing decisions remain separate tracked review work.
