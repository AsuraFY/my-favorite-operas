# Die Fledermaus — German-source preparation checkpoint

**Working branch:** Update; main untouched.

## German source prepared
Three acts transcribed with original scene/order information. There are **2,294 source line records** split as 772 / 903 / 619, including spoken text, sung lyrics, and stage directions in the Sottovoce classification (source labels many dialogues as sung, to audit later). Each of the three acts contains seven source divisions including the unnumbered opening location/overture.

Source: Carl Haffner and Richard Genée, public-domain original libretto, structured [Sottovoce Q464930](https://github.com/martin-he543/sottovoce/blob/ff573f9e35a565bdb6afed35c83f091e69f5a40b/public/libretti/texts/Q464930.json), derived from [Opera Guide](https://opera-guide.ch/operas/die+fledermaus/libretto/de/). Cross-reference [DraCor TEI](https://github.com/dracor-org/gerdracor/blob/2ea43a1bd5206fbb64dc4145b76a09715ce3df43/tei/haffner-die-fledermaus.xml) and [the public-domain original score](https://digital.wienbibliothek.at/wbrobv/content/titleinfo/284303).

## English translation status
An independent English working translation has started, using source-line indices for the opening appearance of Act I. It is intentionally **partial**, is not a modern rights-restricted edition, and should not be presented as a full bilingual libretto. Complete each source line in all three acts, including spoken dialogue and stage directions; verify each scene's grouping and resolve bilingual line pairing before registering in the loader. Do not use an existing modern English translation without permission.

## Publishing guardrail
Do not register the staged source as a finished reader or use placeholders presented as English translations. Preserve the established three-line headings and reader navigation only after translation coverage is complete. Review source scene divisions and actor credits; run all node/browser checks on Update. **Never touch main without explicit user authorization.**
